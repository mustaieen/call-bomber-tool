# 📞 Call Bomber Tool (Termux/Linux/Windows)

পাইথন দিয়ে তৈরি একটি প্রিমিয়াম কল বোম্বার টুল। এতে রয়েছে সুন্দর নিয়ন ইন্টারফেস, লাইভ কল স্ট্যাটাস এবং সহজ কনফিগারেশন।

## ⚡ ফিচারসমূহ (Features)
- 🎨 প্রিমিয়াম নিয়ন সিএলআই ইন্টারফেস (Premium Neon CLI Interface)
- 🚀 লাইভ কল স্ট্যাটাস এবং ফাইনাল রিপোর্ট (Live Call Status & Final Report)
- ⚙️ সহজে কনফিগারযোগ্য (Target Number & Call Count are hardcoded inside the script)
- 🛑 কিবোর্ড ইন্টারাপ্ট (Ctrl+C) হ্যান্ডেল করা (Handles Keyboard Interrupt gracefully)

## 📥 ইনস্টলেশন এবং ব্যবহার (Installation & Usage)

### টার্মাক্সের জন্য (For Termux - Android)
```bash
pkg update && pkg upgrade -y
pkg install python -y
pip install requests
git clone https://github.com/mustaieen/call-bomber-tool.git
cd call-bomber-tool
python main.py


## উইন্ডোজ / লিনাক্সের জন্য (For Windows / Linux)

git clone https://github.com/mustaieen/call-bomber-tool.git
cd call-bomber-tool
pip install -r requirements.txt
python main.py
